I’m an Autonomous AI Systems Engineer at GymBeam. Outside work, I’m building an open-source beatmaking app and making hackathon projects with [null.checked](https://github.com/null-checked).

## What I work on

- **Applied AI and automation.** I build LLM-powered workflows and the APIs around them. In [OneShot](https://github.com/null-checked/OneShot), our team built an agent pipeline that plans coding tasks, reviews changes, and runs tests.
- **Developer tooling.** I build tools that fit into developers’ existing workflows, including an IntelliJ plugin that can run with a local model.
- **Desktop software and real-time audio.** In Grooviq, I’m building a Rust audio engine and a React interface for beatmaking.

## Selected projects

### [Grooviq](https://github.com/YuriiMurha/grooviq)

A free, open-source desktop DAW for beatmakers. I’m building the real-time audio engine and a workflow for sketching beats quickly.

*Pre-alpha · Rust · Tauri · React · TypeScript*

<a href="https://github.com/YuriiMurha/grooviq"><img width="400" alt="Grooviq project banner" src="https://raw.githubusercontent.com/YuriiMurha/grooviq/main/docs/images/banner.png"></a>

### [RubberDuck Live](https://github.com/null-checked/hack-kosice-2026)

An IntelliJ plugin we built at Hack Košice. It notices when you’re stuck and asks a question to help you move forward. It can also run with a local model.

*null.checked · Kotlin · FastAPI · Next.js · Ollama*

<a href="https://github.com/null-checked/hack-kosice-2026"><img width="400" alt="RubberDuck Live project banner" src="https://raw.githubusercontent.com/null-checked/hack-kosice-2026/main/docs/assets/banner.png"></a>

### [DocSnap](https://github.com/YuriiMurha/docsnap)

A warehouse receiving prototype that compares a delivery note with pallet photos and shows what matches, what’s missing, and what’s extra.

*TypeScript · React · TanStack Start*
